# Java Console Banking System

A console-based banking system built in Java demonstrating Object-Oriented Programming principles.

## Features
- Create multiple account
- Secure login using PIN authentication
- Deposit and withdraw money
- Transfer funds between accounts
- Check balance
- View transaction history
- Persistent data storage using file handling
- Exception handling for safe user input

## Technologies Used
- Java
- OOP
- ArrayList
- File Handling

## Concepts Demonstrated
- Encapsulation
- Constructors
- Collections
- Loops & Switch statements
- Input validation & exception handling
- File Reading and Writing

## Sample Functionality
- Create account with PIN
- Login system
- Perform transactions
- Save and load account data
